# 安装与使用

本仓库是**源码仓库**。想直接用（不需要 C++ 环境）请到 [Releases](../../releases)
下载对应引擎版本的预编译包；想自己编译或改代码，按本文第二节操作。

---

## 一、用预编译包（推荐）

1. 到 [Releases](../../releases) 下载 `HistogramAssistant_UE5.5_v1.0.zip`
2. 解压后双击 `1-安装到某个工程.bat`，把你**工程文件夹**拖进窗口回车
   - 脚本会把插件拷到 `<工程>/Plugins/HistogramAssistant`
   - 并自动在 `.uproject` 里加启用条目（同时备份原文件）
3. 打开工程 → `Tools（工具）→ 直方图助手`

想装到引擎级（所有工程可用）：把 `HistogramAssistant` 整个文件夹放到
`<引擎>/Engine/Plugins/Marketplace/`，然后在 `Edit → Plugins` 里勾选。

手动安装也行：把 `HistogramAssistant` 复制到 `<工程>/Plugins/` 即可。

---

## 二、从源码编译

### 前置条件
- 对应版本的 UE 引擎
- Visual Studio 2022，勾选「使用 C++ 的游戏开发」工作负载

### 命令行编译（BuildPlugin）

```bat
"C:\Path\To\UE_5.5\Engine\Build\BatchFiles\RunUAT.bat" BuildPlugin ^
  -Plugin="D:\Path\To\HistogramAssistant\HistogramAssistant.uplugin" ^
  -Package="D:\out\HistogramAssistant" ^
  -TargetPlatforms=Win64
```

产出在 `D:\out\HistogramAssistant\Binaries\Win64\`。

### 或者在编辑器里编译

1. 把插件文件夹放到 `<工程>/Plugins/`
2. 打开工程，UE 会提示"缺少模块，是否重新编译" → 选是
3. 编译完成后重启编辑器

### 编译注意

- **必须先关闭编辑器**，否则报 `Unable to build while Live Coding is active`
- **链接失败会把旧 DLL 删掉**，失败后要立刻修好重编，否则插件加载失败、面板消失
- 改完代码后如果面板不见了，先看 `Saved/Logs/*.log` 里有没有模块加载错误

## 三、使用

1. 打开一个 3D 视口并保持激活
2. `Tools → 直方图助手`，面板可拖到侧边停靠
3. 点「捕获视口」，或勾选「自动刷新（0.5 秒）」

| 想做的事 | 用哪个功能 |
|---|---|
| 判断曝光是否正常 | 直方图 + 底部「直方图诊断」 |
| 看哪块死黑、哪块削波 | 伪彩色（IRE）/ 斑马纹 |
| 只看明暗关系，不看颜色 | 黑白预览 |
| 改灯光前后对比 | A/B 对比（存参考帧 → 并排 / 擦除 / 差异） |
| 存档或发给别人 | 四合一 PNG 导出 |
| 查场景三角面 / 贴图体积 | 选中对象统计（点明细行可跳到资产） |

### 伪彩色档位（对齐 RED 官方 IRE）

| 档位 | 含义 |
|---|---|
| 紫 (0–4) | 死黑 |
| 蓝 (4–10) | 深阴影 |
| 青 (10–12.5) | 阴影边界 |
| **绿 (41–48)** | **18% 中灰基准** |
| **粉 (61–70)** | **肤色** |
| 麦秆 / 黄 / 橙 (92–98.5) | 高光过渡 |
| **红 (98.5+)** | **削波** |

非关键档统一显示灰度（`bDesaturateOthers`），避免满屏色块看不清结构。

## 四、排错

| 现象 | 原因 / 处理 |
|---|---|
| Tools 菜单里找不到 | `Edit → Plugins` 里确认已勾选；改完要重启编辑器 |
| 提示模块需要重新编译 | 引擎版本与 DLL 不匹配，按第二节编译对应版本 |
| 面板出现但直方图是空的 | 需要有**激活的 3D 视口**，点一下视口再捕获 |
| 伪彩色看起来"没覆盖模型" | 历史 bug，alpha 通道问题，已在 1.0 修复 |
| 报 `Unable to find plugin '...'` | `.uproject` 里有启用但磁盘缺失的插件，把那条改成 `false` |
| 面板报的贴图尺寸比预期大 | 先查材质实例是否引用了**其他包的贴图**（常见于资产迁移后） |

---

## 五、卸载

- 工程级：删掉 `<工程>/Plugins/HistogramAssistant`，并从 `.uproject` 删掉对应条目
- 引擎级：删掉 `Engine/Plugins/Marketplace/HistogramAssistant`

插件是纯编辑器模块（Editor Module），不会被打进打包出的游戏。
